## 📖 Course Overview

This is a complete, hands-on Git & GitHub course built for people who are starting **from zero**. Maybe you've heard that every developer needs Git, but never understood what it actually does.

Over two hours, you'll install Git, set it up properly with SSH, learn every core command by typing it yourself, break things on purpose (including a real **merge conflict**), fix them, and finish by pushing a project to **GitHub**.

No fluff, no jargon dumps. Each command is introduced with a real-world reason for why you need it, then demonstrated live in the terminal.

## 🧰 Quick Command Cheat Sheet

```bash
# Setup
git --version
git config --global user.name "your-username"
git config --global user.email "your-email@example.com"
git config --global --list

# Start tracking a project
git init
git status
git status -s

# Stage & commit
git add <file>
git add .
git commit -m "Your message"
git diff
git diff --staged

# History
git log
git log --oneline
git log -5
git log --author="name"

# Undo
git restore <file>
git restore --staged <file>
git reset --soft HEAD~1
git reset --mixed HEAD~1
git reset --hard HEAD~1
git revert <commit-id>

# Branches
git branch
git branch --show-current
git switch <branch>
git switch -c <new-branch>
git branch -d <branch>
git branch -D <branch>

# Merge & cherry-pick
git merge <branch>
git cherry-pick <commit-id>

# GitHub
git remote add origin <repo-url>
git push -u origin main
git clone <repo-url>
git fetch origin
git pull
```

> ⚠️ `git reset --hard` permanently deletes uncommitted work. Use it only for practice.
